# CICLO1

Aplicación web basada en React, Vite y TanStack Start.

## Desarrollo local

Requiere Node.js 22+.

```bash
npm install
npm run dev
```

## Despliegue

El proyecto está preparado para Vercel. El comando de compilación es:

```bash
npm run build
```

Las variables secretas/API deben configurarse como Environment Variables del proveedor de despliegue y nunca guardarse en el repositorio.
